## 2. AI-Related References Found

The audit scanned for references to known AI tools, agents, assistants, models, and generative labels (e.g., `antigravity`, `gemini`, `claude`, `chatgpt`, `copilot`, `cursor editor`, `v0.dev`, `ai-generated`, `generated by ai`, `built by ai`, `powered by ai`, `ai assistant`, `ai agent`).

### Summary of Findings:
1. **Three Temporary Scratch Scripts**:
   - `scratch/extract_css.cjs`, `scratch/find_staff_styles.cjs`, and `scratch/find_transcript_styles.cjs` contained hardcoded scratch file paths referencing the local user's `.gemini/antigravity/brain/...` transcript directory from earlier style extraction sessions.
2. **One Technical Report Sentence**:
   - In `STAGE_4_FINAL_CLARIFICATIONS.md` (line 83), the report phrased headless execution limits as:  
     `"Running in a background agent sandbox cannot render a physical Windows graphical desktop window..."`
3. **False Positive Domain Matches Identified**:
   - Version strings (`v0.3.0` matching `\bv0\b`).
   - CSS properties (`cursor: pointer`, `cursor: grab`, `cursor-not-allowed` matching `\bcursor\b`).
   - Third-party open source licenses (`LICENSES.chromium.html` containing standard Apache 2.0 clause *"within a display generated by the Derivative Works"* and header *"Generated by licenses.py"*).
   - Human roles in ticketing RBAC (`Support Agent`, `Support Agent investigates, replies in thread`).
   - Standard browser DOM APIs (`window.prompt(...)`).
   - Cryptographic HMAC generation in payment webhooks (`const generated = crypto.createHmac(...); return generated === signature;`).
